# Тусовка 🟡

Сервіс подій: створюй зустрічі з обмеженою кількістю місць, записуйся на чужі, коментуй.
Стек: Python 3.11+ · Flask · SQLite · Argon2 · Pillow · Waitress.

## Можливості

- Реєстрація, вхід і вихід за email та паролем.
- Створення події: назва, опис, дата й час, кількість місць, обкладинка, публічна чи приватна.
- Головна: майбутні публічні події, пошук за назвою, сторінки.
- Сторінка події: «Іду» / «Скасувати запис», лічильник вільних місць, коментарі.
- Автор редагує й видаляє подію, бачить список учасників, може видаляти коментарі.
- Приватні події доступні лише за посиланням-запрошенням, яке можна перевипустити.
- Профіль: мої події та події, на які я записався.

## Запуск

Потрібен Python 3.11 або новіший.

**Windows (PowerShell):**

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
.\.venv\Scripts\python.exe run.py
```

**macOS / Linux:**

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/python run.py
```

Застосунок відкриється на <http://127.0.0.1:8000>. База даних і обкладинки створюються автоматично в `instance/`.

## Тести

Одна команда, тестова база створюється в тимчасовій теці:

```bash
python -m pytest
```

Тести перевіряють не лише «щасливий шлях»: гонку записів (20 паралельних запитів на 3 місця), чужі редагування й видалення (403), доступ до приватних подій без токена (404), XSS у коментарях, SVG/HTML замість картинки, завеликі файли, CSRF, відкриті редиректи, повторне використання cookie після виходу, дати в минулому, кількість місць 0 / −10 / 999999999, зменшення місць нижче кількості учасників, обмеження частоти входів.

## Змінні середовища

| Змінна | Обов'язкова | За замовчуванням | Опис |
|---|---|---|---|
| `SECRET_KEY` | у продакшені | випадкова при кожному запуску | Ключ підпису cookie, мінімум 32 символи. Згенерувати: `python -c "import secrets; print(secrets.token_hex(32))"` |
| `TUSOVKA_ENV` | ні | `development` | `production` вмикає Secure-cookie, HSTS і не дає запуститися без `SECRET_KEY` |
| `DATABASE_PATH` | ні | `instance/tusovka.db` | Файл SQLite |
| `UPLOAD_DIR` | ні | `instance/uploads` | Тека для обкладинок |
| `APP_TIMEZONE` | ні | `Europe/Kyiv` | Часовий пояс, у якому вводиться й показується час подій |
| `TRUSTED_PROXIES` | ні | `0` | Кількість reverse-proxy перед застосунком (на Render/Fly — `1`) |
| `HOST`, `PORT` | ні | `127.0.0.1`, `8000` | Адреса сервера (на хостингу `HOST=0.0.0.0`) |

## Безпека

- **Паролі** хешуються Argon2. Під час входу відповідь однакова, чи існує такий email, чи ні. Частота входів і реєстрацій обмежена.
- **Сесії** зберігаються на сервері й відкликаються при виході. Cookie має прапорці `HttpOnly` і `SameSite=Lax` (і `Secure` у продакшені). При кожному вході створюється нова сесія.
- **CSRF:** кожна форма має токен, а запити з чужого `Origin` відхиляються.
- **Права доступу** перевіряються на сервері. Редагувати, видаляти подію і бачити учасників може лише автор. Події мають випадкові ID на кшталт `/e/Xk2…`, а не `/events/1`.
- **Приватні події** не з'являються в списку та пошуку. Доступ до них дає лише токен (192 біти), автор або участь у події; інакше сервер відповідає 404. Заголовок `Referrer-Policy: no-referrer` не дає токену витекти на інші сайти.
- **Гонка записів:** перевірка місць і запис виконуються в одній транзакції `BEGIN IMMEDIATE` з умовою в `INSERT … WHERE count < capacity`. Пара `(event_id, user_id)` — первинний ключ, тож записатися двічі не можна.
- **Бізнес-правила:** подія створюється лише в майбутньому (не далі ніж за 3 роки), місць — від 1 до 10 000. Записатися чи скасувати запис після початку події не можна. Кількість місць не можна зменшити нижче кількості учасників.
- **Обкладинки:** до 5 МБ. Перевіряються magic bytes (лише JPEG, PNG, WebP), обмежується кількість пікселів (захист від decompression bomb). Картинка перекодовується Pillow, метадані видаляються, ім'я файлу — новий UUID.
- **XSS:** увесь текст екранується (Jinja autoescape). CSP без inline-скриптів, `X-Frame-Options: DENY`, `nosniff`.
- **Ліміти довжини:** назва — 120 символів, опис — 5000, коментар — 1000. Невидимі й керуючі символи видаляються.
- **Помилки:** клієнт бачить лише зрозумілу сторінку з кодом, без stack trace. Деталі пишуться в лог сервера.
- **Email** інших користувачів ніде не показується, лише ім'я.

## Структура

```
tusovka/
  __init__.py     фабрика застосунку, конфіг, обробка помилок
  auth.py         реєстрація, вхід, вихід
  events.py       події, запис, коментарі, профіль, обкладинки
  security.py     сесії, CSRF, rate limit, заголовки безпеки
  validation.py   валідація форм і дат
  uploads.py      перевірка та перекодування зображень
  db.py           схема SQLite і транзакції
  templates/, static/
tests/            pytest
run.py            запуск через waitress
```
